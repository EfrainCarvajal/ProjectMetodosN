Contenido del reporte

¿Qué incluye cada reporte?

Ambos formatos contienen la misma información analítica, adaptada al mejor uso de cada soporte.

📐
Descripción del modelo

Las 3 EDOs acopladas con sus parámetros y la función de migración dinámica μ(Z).

📈
Estadísticas descriptivas

Valor inicial, final, mínimo, máximo, promedio y variación porcentual de X, Y y Z.

🔁
Análisis comparativo

Relación entre la presión demográfica y la evolución del stock de recursos críticos.

🗂️
Historial completo

Tabla paso a paso de la integración RK4: tiempo, X, Y y Z para cada iteración.

🤖
Conclusión automática

Interpretación generada según el comportamiento de Z: equilibrio, agotamiento o superávit.

📉
Datos para gráfica

Columnas limpias de hasta 200 puntos para insertar un gráfico de líneas en Excel.

Elige el formato

PDF vs Excel

Cada formato está pensado para un propósito distinto. Puedes descargar ambos.

PDF Informe ejecutivo
  • Encabezado y pie de página en cada hoja con número de página y fecha de generación
  • Sistema de ecuaciones con formato matemático legible
  • Tabla de estadísticas con filas alternadas y variación en color
  • Análisis comparativo en prosa, generado automáticamente
  • Tabla muestral del historial (hasta 30 pasos distribuidos)
  • Ideal para presentar, imprimir o adjuntar en un informe académico
Descargar PDF
XLSX Libro de datos
  • 3 hojas: datos completos, estadísticas y análisis, y datos listos para graficar
  • Fórmulas Excel nativas para PROMEDIO — el libro recalcula si cambias datos
  • Variación porcentual con formato % y color naranja para resaltar cambios
  • Conclusión automática embebida en la hoja de estadísticas
  • Columna de hasta 200 puntos muestreados para insertar gráfico de líneas
  • Ideal para explorar los datos, hacer análisis propios o construir gráficas

Flujo de uso

Cómo obtener tu reporte

01
Selecciona provincia

Elige Guayas, Pichincha o Pastaza en el simulador y ajusta los parámetros de tu escenario.

02
Ejecuta RK4

Presiona "Ejecutar simulación". Los resultados se guardan automáticamente en la base de datos.

03
Descarga el reporte

Vuelve a esta página y descarga PDF o Excel. El reporte refleja la última simulación ejecutada.

04
Analiza y comparte

Abre el Excel para construir tus propias gráficas, o adjunta el PDF en tu informe académico.
